Student Registration System Manual

"Towards a Brighter Future "

Step 1: Register as a New Student

အကောင့်သစ်တစ်ခုဖွင့်လိုလျှင် Register New Student button ကိုနှိပ်ပါ။ ပုံတွင်ပြထားသည့်အတိုင်း name,student_ID,email,username,password စသည့် လိုအပ်ချက်များကို မှန်ကန်စွာ ဖြည့်ပါ။

Tip:သင်၏ password နှင့် confirm password ကို မှန်မမှန် စစ်ဆေးပါ။

Step 2: Register as UTYCC Student

UTYCC ကျောင်းသားဟောင်းများအနေဖြင့် Register UIYCC Student button ကိုနှိပ်၍ log in ဝင်ပြီး username နှင့် password ကိုမှန်ကန်စွာဖြည့်ပါ။

Step 3: Login to Student Portal

Once registered, use the login panel on the main page. If your login is correct, you’ll be redirected to the student dashboard.

If your password is incorrect, a warning message will appear.
